# Finanzübersicht

Eine persönliche Desktop-App zur Verwaltung von Einnahmen, Ausgaben und Ersparnissen.

## Download

👉 [Zur neuesten Version](../../releases/latest)

|Betriebssystem|Datei|
|-|-|
|Windows|`Finanzuebersicht.exe` – In gewünschten Ordner legen → direkt starten|
|macOS|`Finanzuebersicht-macOS.zip` –In gewünschten Ordner legen →  entpacken, dann Rechtsklick → Öffnen|

## Features

* Monatliche Einnahmen und Ausgaben erfassen
* Fixkosten jahresweise verwalten
* Kreis- und Balkendiagramme
* Jahresübersicht mit Verlauf
* Automatische Backups
* CSV-Export

## Erster Start auf macOS

Da die App nicht über den Apple App Store verteilt wird, erscheint beim ersten Start eine Sicherheitsmeldung.

**Lösung:** Rechtsklick auf `Finanzuebersicht.app` → „Öffnen" → „Öffnen" bestätigen.
Danach startet die App normal per Doppelklick.

## Technik

* Python 3.11
* tkinter (GUI)
* matplotlib (Diagramme)
